## 🚀 Tech Stack
- **Framework:** React 18 + TypeScript + Vite
- **Styling:** Tailwind CSS with custom 3D Pixar Claymorphism and Glassmorphism utilities
- **Icons:** `lucide-react`
- **Animations:** Custom CSS 3D extrusion, hover elevation, floating keyframes
- **Integration:** Direct WhatsApp quotation integration (`wa.me`) with URL-encoded inquiry formatting

## 📦 Project Setup & Local Development

1. Open this project directory in your terminal or IDE:
   ```bash
   cd "C:\Users\ALL AtoZ\.gemini\antigravity\scratch\tie-corporate-website"
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Build for production (Zero-warning, Vercel-ready):
   ```bash
   npm run build
   ```

4. Preview the production build:
   ```bash
   npm run preview
   ```

---

## 🌐 Deploy to Vercel
1. Push this repository to GitHub or run `vercel` in the project root:
   ```bash
   npx vercel
   ```
2. Build Command: `npm run build`
3. Output Directory: `dist`
4. Install Command: `npm install`
